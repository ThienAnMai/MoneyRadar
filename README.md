# Money Radar

**Money Radar** is a React web application designed to help users discover, compare, and track personalized financial opportunities such as grants, tax credits, and employment benefits tailored to their specific profile.

---

## Features

- **Explore Opportunities:** Browse curated grants, educational funding, and employment benefits with detailed modal views.
- **My Radar & Profile Questionnaire:** Set up profile to receive custom-tailored recommendations.
- **Compare & Plan:** Compare selected opportunities side-by-side and manage saved queue.
- **Active Pursuits:** Track progress with interactive checklists and progress bars for each opportunity.

---

## Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS
- **Code Quality / Linting:** Oxlint
