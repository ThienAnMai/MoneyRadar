## External dependencies

The project is a client-side React application. All icons and image assets are stored directly within the repository. The following packages was used in the project:

| Dependency | Download / project URL | How it is used |
| --- | --- | --- |
| React | [npm package](https://www.npmjs.com/package/react) | Provides the component model and UI state/hooks used throughout the application. |
| React DOM | [npm package](https://www.npmjs.com/package/react-dom) | Mounts the React application into the page’s root element. |
| Vite | [npm package](https://www.npmjs.com/package/vite) | Runs the local development server and bundles the application for production. |
| Vite React plugin | [npm package](https://www.npmjs.com/package/@vitejs/plugin-react) | Enables React/JSX support and React fast refresh in Vite. |
| Tailwind CSS | [npm package](https://www.npmjs.com/package/tailwindcss) | Supplies the utility classes used to style the interface. |
| Tailwind CSS Vite plugin | [npm package](https://www.npmjs.com/package/@tailwindcss/vite) | Integrates Tailwind CSS processing with the Vite build and development server. |
| Oxlint | [npm package](https://www.npmjs.com/package/oxlint) | Provides the lint command declared in the application package manifest. |
| React type definitions | [npm package](https://www.npmjs.com/package/@types/react) | Development-only type declarations for React, available to editor and tooling support. |
| React DOM type definitions | [npm package](https://www.npmjs.com/package/@types/react-dom) | Development-only type declarations for React DOM, available to editor and tooling support. |

Install the JavaScript runtime and npm using [Node.js](https://nodejs.org/en/download/), then run `npm install` in the application directory to install its declared packages. The package lockfiles resolve the transitive packages required by these direct dependencies.
